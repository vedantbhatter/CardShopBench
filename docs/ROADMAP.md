# Release roadmap

## Complete in v0.1
Observed pricing collector; seeded simulation; deterministic accounting; baseline suite; model adapter; research retrieval; import tooling; tests; report site; portable source bundle.

## Next experiment: model pilots
- Choose model provider and verify JSON response support.
- Run 2-day smoke episodes before a paid sweep.
- Pin exact model IDs, prices, prompt, corpus and snapshot hashes.
- Run 3 models × 5 seeds in one scenario, then expand scenarios after examining failures.
- Record incomplete runs and cost; never silently exclude failures.
- Add actual model-run artifacts and their measured findings to the report.

## Data milestones
- Review raw-condition and graded-card sold records.
- Add timestamped active listings with shipping and expiration to the execution environment.
- Verify Tradepost access and Facebook export workflow with user-provided data.
- Expand forum corpus and add retrieval-quality checks.
- Source dated PSA population observations before making low-pop claims.

## Research milestones
- Calibrate demand against real sale/time-on-market observations.
- Keep a held-out scenario family and add same-seed repeats.
- Add discount negotiation, returns, scams and capital concentration limits.
- Introduce human-operated control and competitive arena.
- Begin a prospective 30/60/90-day paper-business track alongside simulations.
