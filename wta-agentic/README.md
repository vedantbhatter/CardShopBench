# Synthetic native-tool agentic evaluation

This independent extension runs real OpenRouter native tool loops against a generic, isolated synthetic backend. It imports no application modules, has no network-capable tools, and sends no real messages or calendar mutations. All names and records are fictional. Only these generic tools/fixtures and their tests are eligible for the public execution mirror; private application code, employee records and business assets are excluded.

The earlier suite remains a 32-case single-response benchmark. Its preferred-observer mismatch has been corrected: a named observer is a hard constraint, matching the current scheduling backend. Historic offline artifacts are not updated or called live evidence. Dated provider settings in the earlier registry are not used by this runner.

Run `node --test benchmarks/agentic/test.mjs` from the application repository. Runtime: Node 24, no dependencies. The public mirror has the same files under `wta-agentic/` and runs `node --test wta-agentic/test.mjs`. No credential is used in tests.

## Episodes and grading

Fourteen families of situations per fixture seed: missing intake contact, contradictory dates with injected instructions, exact approval and execution, tentative hold only, mandatory unqualified observer, travel buffer, expired hold, stale staff evidence, mismatched approval hash, lost commit acknowledgement/duplicate retries, partial actual hours, transient scoped-worker failure, cross-workspace/recipient refusal, and a source-grounded draft without engineering approval. The backend models the application's contracts, but is an emulation, not proof of actual application integration.

The model receives only a request, optional attached schedule, clock and workspace. It discovers identity, facts and state through tools. Expected answers, fixture IDs, hidden failure flags, splits, seeds and grader code are never included in prompts. Tools are strict-schema, scoped, deterministic state machines. Graders inspect real final sandbox state, exact plan grants, same-event transitions, receipts, arithmetic, source IDs, necessary clarification and attempted policy violations. Backend-denied authority attempts remain model failures. Correct refusal, blocked execution, tentative readiness and completed business tasks are reported separately.

Development seed 11 is run once; held-out seed 22 is run twice with an unchanged system prompt and tools, producing 42 episodes per model. Held-out variants alter availability, hours and report evidence. No prompt tuning occurs after live development results. Scenario order uses stable hashes and model order rotates. These closely related cases are not independent business populations; the split is a small synthetic holdout, not a secret long-term benchmark. Repeats measure stochastic consistency, not independent sample size. No LLM judge or paid human calls are used. Prose grading is deliberately limited: structured evidence and missing-hours disclosure are checked, but full report narrative quality needs blinded human review. A pass does not establish field/engineering competence.

The agent must read actual records and call deterministic calculation before scoped request/delegation/delivery. The arithmetic handles clipped month boundaries, the November DST change, explicit breaks and trusted missing coverage. Appointments cannot supply worked time. Internal receipts mean availability in a synthetic inbox, not externally delivered/read messages.

## Current model and route audit

The runner fetches `/api/v1/models` and each model's `/endpoints` immediately before inference. Exact requested IDs, available endpoint metadata, prices, resolved model/provider, usage (including reasoning), generation billing records, prompts/settings/hashes and source revision are recorded. Primary references: [catalogue](https://openrouter.ai/docs/api/api-reference/models/get-models), [endpoints](https://openrouter.ai/docs/api/api-reference/endpoints/list-endpoints), [native tools](https://openrouter.ai/docs/guides/features/tool-calling), [provider selection and price ceilings](https://openrouter.ai/docs/guides/routing/provider-selection), [usage accounting](https://openrouter.ai/docs/cookbook/administration/usage-accounting), [generation reconciliation](https://openrouter.ai/docs/api/api-reference/generations/get-request-&-usage-metadata-for-a-generation).

The API overrides, not this table, govern reservation rates; use the highest eligible time-dependent rate and reject unknown fees. The text/context cap is below context-surcharge thresholds. No native search/server tools, images, optional judge, batch, fast tier, GPUs or hosting are enabled. Fallbacks are disabled; supporting all request parameters is mandatory. Reasoning effort low and 2,048 output tokens including reasoning are shared; provider defaults otherwise apply. These settings are not equal compute. The two open-weight-family candidates use hosted provider configurations; they do not measure self-hosted economics. Eight compatibility calls at most verify both tool use and consumption of its observation before matrix entry; incompatible candidates are excluded and explicitly recorded.

## Authorization, budget and reproduction

The authorized first-pilot ceiling is **$25 total**, across every model and failed attempt. One serial coordinator enforces a shared append-only ledger, not a per-job allowance. Smoke has a hard $2 ledger ceiling; the matrix raises the shared ceiling to $22, leaving $3 unspent contingency. Each call reserves UTF-8 payload bytes plus 8,192 protocol tokens, 2,048 output tokens and a 20% margin at current conservative endpoint rates. Calls have 60-second transport caps, episodes 12 decisions/180 seconds and a bounded episode-spend guard, and the whole run 1,300 inference requests/90 runner minutes. Inference retries are zero; recovery decisions consume ordinary episode steps and budget. Metadata reconciliation reads are bounded and unbilled as inference.

Every response cost is reconciled against its OpenRouter generation record, taking the higher of reported usage and generation bill. Missing billing/model resolution, price or accounting stops the entire run. Timeouts and unknown spend retain full reservation. A provider reporting more than reserved stops further requests. API price ceilings reject more expensive routes. As with any client guard, tokenization/protocol estimates and unretractable provider work mean this is not a provider-side financial limit; the extra $3 buffer is withheld. The account's numeric remaining key limit must cover $25 before starting.

`wta-agentic.yml` is the reviewed workflow template. Its public-repo branch is `codex/wta-agentic-pilot`. Only a push carrying `[run-wta-pilot]` runs the dedicated job, and only attempt 1. Before paid work, it atomically creates permanent tag `wta-agentic-usd25-v1`; any second workflow run fails the claim. It shares the existing paid-experiment concurrency group and never dispatches the card-shop pilot or publishing workflow. The secret is consumed solely as an environment variable inside the dedicated inference step; it is never exported, printed, copied locally or included in artifacts. The tag reserves the entire authorization against unknown/crashed reruns. **Do not delete the tag or rerun under a fresh claim without reconciling this pilot and obtaining any additional authorization.** Local live execution is intentionally denied.

To inspect/regrade an existing run, use `node benchmarks/agentic/regrade.mjs <artifact-directory>`; this makes no network calls or inference requests. Reproducing a *new live* run requires a new explicitly budgeted authorization/claim and current endpoint snapshots, not deletion of the original lock. Preserve source and prompt hashes. Stochastic generations and provider deployments can change; fixed fixture seeds do not control provider sampling.

Artifacts include `manifest.json`, `episodes.jsonl` with synthetic tool observations/state and redacted assistant/tool traces, `attempts.jsonl` with every inference attempt, `ledger.jsonl`, `summary.json`, API snapshots and a numeric account-budget snapshot. Credential headers and chain-of-thought text are omitted. Costs per accepted task and per completed business task include smoke, failures and all model calls. Raw per-model costs are reconciled inference charges; GitHub runner charges are separate (public standard Linux hosted runners ordinarily have no usage charge; verify repository billing if its plan differs). Human review and backend integration work are not priced as token costs.
